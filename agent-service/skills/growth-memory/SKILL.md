## 何时使用

用户直接用第一人称声明稳定的兑换目标、奖品类别偏好或任务偏好，或者查询、修改、记住、遗忘这些信息时使用。用户不需要额外说“请记住”。只对本轮有效的临时需求不能自动沉淀。

## 输入

兑换目标需要奖品 ID 和目标日期；偏好需要明确的喜欢类别、不喜欢类别或任务类型；遗忘需要明确范围。

## 执行步骤

先区分稳定陈述与临时条件，再读取或校验必要数据。稳定目标和偏好校验通过后直接写入；遗忘按用户明确指定的范围直接执行，不增加重复确认。更新偏好前先读取已有记忆并合并，避免完整替换语义误删其他偏好。

## 错误与重试

奖品查询失败、日期无效或偏好冲突时不写入。带有“这次、今天、当前、先”等临时范围，或者表达含糊、低置信度时，不写入或先澄清，不根据模型推断补写。

## 安全边界

不保存敏感信息、积分、库存、订单状态、任务完成状态等动态事实；不从浏览、兑换、点击和推荐选择中推断稳定偏好；不同用户的长期记忆必须隔离，并保留更新时间和来源会话。

## 输出

查询返回已保存的兑换目标和偏好；写入或遗忘操作返回变更后的长期记忆。
