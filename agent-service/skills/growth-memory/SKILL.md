## 何时使用

用户主动要求记住兑换目标、奖品类别偏好、任务偏好，或者查询、修改、遗忘这些稳定信息时使用。普通闲聊中提到的内容不能自动沉淀。

## 输入

兑换目标需要奖品 ID 和目标日期；偏好需要明确的喜欢类别、不喜欢类别或任务类型；遗忘需要明确范围。

## 执行步骤

先判断用户是否明确表达了记忆意图，再读取或校验必要数据。目标和偏好校验通过后直接写入；遗忘按用户明确指定的范围直接执行，不增加重复确认。

## 错误与重试

奖品查询失败、日期无效或偏好冲突时不写入。表达含糊、低置信度或疑似临时情绪时先澄清，不根据模型推断补写。

## 安全边界

不保存敏感信息、积分、库存、订单状态、任务完成状态等动态事实；不从用户随口表达中推断稳定偏好；不同用户的长期记忆必须隔离，并保留更新时间和来源会话。

## 输出

查询返回已保存的兑换目标和偏好；写入或遗忘操作返回变更后的长期记忆。
