# 活动草案规划

## 何时使用

仅用于运营活动的分析和草案生成。普通用户咨询积分或兑换时不使用。

## 输入

输入活动目标、已经定义的目标用户群、奖品金额预算、任务积分发放上限、活动起止时间，以及任务和奖品数量上限。金额预算以分为单位，积分与金额之间不做固定换算。

## 执行步骤

1. 先检查运营人员是否已经给出活动目标、目标客群、现金预算、积分发放上限和包含时区的起止时间；缺少时只追问必要参数。
2. 参数齐全后调用一次 `draft_campaign_plan`，不要提前重复查询规划快照。
3. 草案 Service 会读取用户群规模、任务规则、奖品库存、单位成本和历史参与率，并检查快照与时间窗口。
4. 根据返回结果分别说明预计发放积分、计划奖品成本、来源和风险；不得把草案说成已发布活动。
5. 数据不足时列出缺失事实，不使用模型常识补齐参与率、库存或成本。

## 错误与重试

数据缺失或快照过期时返回待补数据，不猜测参与率、库存、单位成本或用户群规模，也不使用兑换积分反推人民币成本。只读数据源短暂不可用时可以刷新后重试。

## 安全边界

该 Skill 只生成草案，不提供活动发布、规则修改、库存修改或积分发放能力。所有草案必须经过运营人员编辑和人工审核。

## 输出

输出结构化活动草案，包含建议任务、建议奖品及数量、预计参与人数、预计发放积分、计划奖品成本、风险和来源快照信息。
