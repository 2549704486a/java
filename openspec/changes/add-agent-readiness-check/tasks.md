- [ ] 1.1 为 Java 业务 API 客户端增加独立短超时的 Actuator 健康探针，并用定向客户端测试验证 `UP`、非成功状态和超时均被稳定转换。
- [ ] 1.2 为确认存储和长期记忆存储协议增加只读就绪探针：内存后端只检查本地实例，Redis 使用 `PING`，MySQL 使用 `SELECT 1`；用各后端的定向测试验证不调用 `stats()`。

## 2. Agent 存活与就绪 API

- [ ] 2.1 在运行时聚合当前配置对应的必需组件状态，捕获超时和异常并输出脱敏结果；用定向测试验证全 `UP`、单组件 `DOWN` 和未启用后端三类结果。
