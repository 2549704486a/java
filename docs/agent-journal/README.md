# Agent 项目任务日记

> 本目录按时间记录 Agent 项目中已经完成的任务。它不局限于评测，也可以记录需求梳理、代码开发、环境搭建、测试、文档整理和问题排查。

## 记录规则

1. 任务真正完成并完成必要验证后再记录，不把计划中的工作写成已完成。
2. 每条记录至少包含完成时间和任务内容概述；有明确产物或验证结果时一并简要记录。
3. 日记只写结果和范围，不复制设计文档、测试报告或大段代码。
4. 历史补录无法确定精确时刻时，必须注明时间来源，不进行猜测。
5. 同一天的小修复可合并记录，能够独立形成阶段成果的任务单独记录。
6. 仅用户要求或阶段性交接确有必要时更新日记；不要求每项任务例行追加，不读取整份历史。提交规则遵循根目录 `AGENTS.md`。

主文件：`任务日记.md`。
