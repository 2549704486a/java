## 3. 推荐学习顺序

1. 沿一次自然语言请求读完 `main.py -> agent.py -> tools.py -> points_plan.py -> api_client.py`。
2. 在阅读 `models.py` 时专题学习 Pydantic，理解数据如何进入和离开 Agent。
3. 结合一次真实工具调用学习 Function Calling，以及 Tool 描述如何影响模型选择。
4. 阅读积分规划分支和任务组合算法，区分模型推理与确定性业务计算。
5. 结合现有单元测试学习 Fake、MockTransport、异常路径和回归保护。
6. 结合已完成的 HTTP 服务学习 FastAPI 生命周期、同步路由线程池和 Agent 缓存边界。
