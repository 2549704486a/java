# Agent 开发学习文档

> 本目录记录“为了真正理解当前 Agent，还需要掌握哪些技术”。它服务于学习和复盘，不参与业务 Agent 运行，也不代替代码与面试文档。

## 文件分工

| 路径 | 用途 |
| --- | --- |
| `00_技术学习清单.md` | 技术点总账、学习状态、代码证据和总结去向 |
| `topics/` | 已经展开讲解的专题笔记；一项技术讲清后再创建对应文件 |

## 维护规则

1. 阅读或修改代码时发现新的框架、机制、算法或工程决策，应先补充到技术学习清单。
2. 当前任务必须理解的内容立即讲解；只涉及底层原理的内容先标记为待深入，不中断开发主线。
3. 学习状态必须以代码阅读、实验或测试为依据，不能因为课程提到过就标记为已理解。
4. 项目阶段总结前，按清单逐项检查，不依赖对话记忆补技术点。
5. 工程实现写入 `agent-design/`，面试表达写入 `agent-interview/`，本目录保留学习过程和原理。
