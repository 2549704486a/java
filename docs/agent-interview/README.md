# Agent 面试文档

> 这里不是开发日志，而是从真实实现中提炼面试表达。当前只记录最小 Agent 阶段，后续随功能迭代逐步补充，项目结束后再形成完整总结。

## 使用原则

1. 先有代码、测试或实验，再写结论。
2. 每个结论都能指向对应实现，不虚构生产收益。
3. 优先记录“为什么这样设计、替代方案是什么、如何验证”，而不是背框架 API。
4. 阶段文档保持简短，最终总结统一处理重复内容。
