# 本地环境一键启动

> 本地开发不再逐个点击快捷方式。统一脚本按依赖顺序启动并检查端口，重复执行时会跳过已经运行的服务。

## 1. 一键启动

双击项目根目录的 `start-local.bat`，或在 PowerShell 中执行：

```powershell
cd D:\工作\incentive-事务消息
.\start-local.ps1
```

启动顺序：

```text
MySQL -> Redis -> RocketMQ NameServer -> RocketMQ Broker
      -> Canal -> RocketMQ Dashboard -> Spring Boot 应用
```

Spring Boot 应用同时包含 HTTP 受理端和本项目 RocketMQ 消费者，不需要启动 `start_consumer.bat.lnk`。该快捷方式对应的是 RocketMQ 官方 QuickStart 示例消费者。

## 2. 常用参数

```powershell
# 只查看状态，不启动任何服务
.\start-local.ps1 -Action Status

# 不启动非必要的 RocketMQ Dashboard
.\start-local.ps1 -SkipDashboard

# 只启动中间件，Java 应用仍从 IDEA 启动
.\start-local.ps1 -SkipApp

# 强制重新 Maven 打包后启动
.\start-local.ps1 -Rebuild
```

## 3. 状态与日志

脚本检查以下端口：

| 服务 | 端口 | 是否必要 |
| --- | ---: | --- |
| MySQL | 3306 | 是 |
| Redis | 6379 | 是 |
| RocketMQ NameServer | 9876 | 是 |
| RocketMQ Broker | 10911 | 是 |
| Canal | 11111 | 是 |
| RocketMQ Dashboard | 8080 | 否 |
| Spring Boot | 8088 | 是 |

后台进程日志写入 `.local-runtime/logs/`。启动失败时先看对应的 `.err.log` 和 `.out.log`。
