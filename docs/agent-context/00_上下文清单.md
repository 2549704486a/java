# 上下文选读规则

本页仅供查阅，不是必读层。以根目录 `AGENTS.md` 为唯一默认项目上下文入口。

| 内容 | 加载条件 |
| --- | --- |
| 当前源码与直接调用方 | 回答当前代码问题或实施变更所必需 |
| 当前 change 的任务与规格片段 | 正在实施对应复杂需求 |
| 产品说明、专项设计与上下文文档 | 源码不能解释当前业务含义或设计取舍时选读 |
| 日记、面试材料 | 用户要求回顾，或需要追查特定历史决定 |
| 路线图、课程索引、讲义、逐字稿、学习目录 | 仅用户本次明确要求加载指定内容 |

优先读取局部内容，按需扩大。会话中已读且未变化的内容复用；不沿链接自动读取，不因续接任务重新加载全部背景。当前源码和运行证据高于旧文档，实验和计划不能替代已实现事实。
