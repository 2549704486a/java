# Agent 课程索引

> 课程不是一次性背景资料，而是工具箱。先判断当前任务缺少哪种能力，再只加载对应课时；需要细节时，优先看讲义中的完整案例，再用逐字稿补足老师的解释。

课程根目录：`D:\工作\八股文\Agent开发课程\Agent`

## 1. 加载规则

1. 默认只读本索引，不读取十二节全部材料。
2. 每次最多先加载一至两节，确认不足后再扩展。
3. 同一课时优先级：主讲义和案例文档 > 逐字稿 > 面试题。
4. 老师举的例子属于重要语料；真正使用某课时时，应保留例子的输入、处理过程、输出和它所解释的原理。
5. 教辅资料只在索引明确指向或任务直接需要时加载。

## 3. 本项目建议的首轮加载

如果目标尚未进一步明确，只加载以下内容：

1. 第一节：判断 Agent 在积分激励业务中的职责。
2. 第三节：设计只读查询工具和受控写工具。
3. 第十节：用 Skill 管理触发条件、权限、幂等和渐进披露。

等确定需要知识库、记忆、多 Agent、MCP 或部署后，再分别加载第五、七、八、九、十一节。不要因为课程中介绍了某项技术，就默认项目必须采用它。
