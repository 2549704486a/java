## 5. 配置入口

| 配置组 | 文件 | 关键环境变量 |
| --- | --- | --- |
| MySQL | `application-dev.properties`、`application-prod.properties` | `SPRING_DATASOURCE_URL`、`USERNAME`、`PASSWORD` |
| Redis | 同上 | `SPRING_DATA_REDIS_HOST`、`PORT`、`USERNAME`、`PASSWORD` |
| RocketMQ | `application.properties` 和环境配置 | `ROCKETMQ_NAME_SERVER`、Topic、生产者组、消费者组 |
| Canal | `application.properties` | `CANAL_HOST`、`PORT`、订阅表达式、批量大小、轮询间隔 |
| 缓存预热 | `application.properties` | `CACHE_WARM_*` |
| 旧链路重试 | `application.properties` | `SECKILL_OLD_CHAIN_*` |
| Agent 确认存储 | `agent-service/.env` | `EXCHANGE_CONFIRMATION_STORE`、`EXCHANGE_CONFIRMATION_REDIS_URL`、`EXCHANGE_CONFIRMATION_REDIS_PREFIX` |

配置文件只保存占位符和本地默认值，Agent 不应把密码写入 Prompt、日志或代码。

## 6. 当前默认重试配置

- 线程内探测轮数：2
- 退避列表：5ms、15ms
- 分片锁过期：10 秒
- 自定义延迟重试：开启
- 自定义延迟重试上限：6
- 延迟级别：`1,1,2,2,3,4`
- RocketMQ 原生最大重试次数：3

延迟级别对应的真实时长由 Broker 配置决定，不能只根据数字自行假设。

## 7. 构建与验证

```powershell
cd D:\工作\incentive-事务消息\incentive
mvn -q -DskipTests package
```
